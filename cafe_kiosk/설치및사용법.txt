    Windows / Linux / Raspberry Pi 크로스플랫폼 지원

[권장 환경]
  - Python 3.9 이상
  - 마이크 (USB 마이크 권장)
  - 터치스크린 또는 일반 모니터 + 마우스
  - 인터넷 연결 (Google STT 사용 시)
  - 운영체제: Windows 10/11, Raspberry Pi OS (Bullseye / Bookworm), Ubuntu 등 Linux

【Windows 설치】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1단계 — Python 패키지 설치

  pip install SpeechRecognition pyaudio pyttsx3 edge-tts Pillow

  # (강력 권장) TTS 응답 속도 대폭 향상 (500ms → 50ms)
  pip install pywin32

  # (선택) Dialogflow 자연어 인식 사용 시
  pip install google-cloud-dialogflow

각 패키지 역할:
  SpeechRecognition    → 마이크 음성을 텍스트로 변환 (Google STT 연동)
  pyaudio              → 마이크 입력 처리
  pyttsx3              → TTS 음성 목록 조회용 (실제 재생은 SAPI5 직접 사용)
  edge-tts             → Edge 온라인 TTS, 캐시 재생
  Pillow               → 키오스크 메뉴 카드 이미지 표시 (PNG 로딩·리사이즈)
  pywin32              → Windows SAPI5 COM 직접 접근 (TTS 속도 최적화)
  google-cloud-dialogflow → 자연어 인텐트 인식 (선택사항)

  ※ pyaudio 설치 실패 시 ("error: Microsoft Visual C++..." 오류):
     pip install pipwin
     pipwin install pyaudio

  ※ Windows TTS 동작 방식:
     [방법 1 — 권장] pywin32 설치 시: SAPI5 COM 객체를 직접 재사용 → 빠른 응답
     [방법 2 — 폴백] pywin32 미설치 시: PowerShell System.Speech 를 매번 실행
     어느 방법이든 한국어 TTS 를 사용하려면 Windows 설정 → 시간 및 언어 →
     언어 → "한국어" 언어팩(Microsoft Heami 등)이 설치되어 있어야 합니다.
     언어팩이 없어도 앱은 정상 실행되며, TTS 안내 음성만 영어로 출력됩니다.

1단계 — 시스템 패키지 설치

  sudo apt update && sudo apt upgrade -y

  sudo apt install -y \
      python3-pip \
      python3-venv \
      python3-dev \
      python3-tk \
      build-essential \
      pkg-config \
      x11-xserver-utils \
      alsa-utils \
      portaudio19-dev \
      libportaudio2 \
      libportaudiocpp0 \
      libasound2-dev \
      mpg123 \
      espeak-ng \
      espeak-ng-data \
      fonts-noto-cjk \
      fonts-noto-color-emoji \
      python3-pil \
      python3-pil.imagetk

각 패키지 역할:
  python3-pip          → pip 패키지 관리자
  python3-venv         → 가상환경 생성
  python3-dev          → PyAudio 같은 C 확장 패키지 빌드 헤더
  python3-tk           → tkinter GUI 라이브러리
  build-essential      → gcc / make 등 빌드 도구
  pkg-config           → pip 빌드 중 라이브러리 경로 감지
  x11-xserver-utils    → xrandr 모니터 감지 도구 (RPi 5인치/7인치 자동 배치)
  alsa-utils           → aplay / arecord 오디오 장치 확인 도구
  portaudio19-dev      → 마이크 입력에 필요한 오디오 라이브러리 (PyAudio 빌드 의존성)
  libportaudio2        → PortAudio 실행 라이브러리
  libportaudiocpp0     → PortAudio C++ 실행 라이브러리
  libasound2-dev       → ALSA 사운드 라이브러리 (PyAudio 빌드 필수)
  mpg123               → Edge TTS mp3 재생기
  espeak-ng            → 오프라인 TTS 엔진 (한국어 음성 출력)
  espeak-ng-data       → espeak-ng 한국어 음성 데이터 (TTS 한국어 지원 필수)
  fonts-noto-cjk       → 한국어 폰트 (UI 한글 표시)
  fonts-noto-color-emoji → 이모지 폰트 (이미지 없는 메뉴 폴백용)
  python3-pil          → Pillow 이미지 라이브러리 (메뉴 이미지 로딩)
  python3-pil.imagetk  → Pillow ↔ tkinter 연동 (PhotoImage 변환)

  ※ python3-pil.imagetk 가 별도 패키지로 없는 구버전 OS:
     python3-pil 만 설치되어 있으면 ImageTk 가 포함되어 있습니다.
     설치 오류 시 해당 줄을 제거하고 진행하세요.


2단계 — Python 패키지 설치

  # 권장: 가상환경에서 설치
  python3 -m venv ~/venv-cafe
  source ~/venv-cafe/bin/activate
  python -m pip install --upgrade pip setuptools wheel
  pip install -r requirements-rpi.txt

  # Bookworm에서 시스템 Python에 직접 설치해야 하는 경우만 사용
  pip3 install --break-system-packages -r requirements-rpi.txt

requirements-rpi.txt에 포함된 주요 pip 패키지:
  SpeechRecognition    → Google STT 음성 인식
  PyAudio              → 마이크 입력 처리
  pyttsx3              → TTS 음성 목록 조회 및 오프라인 TTS
  edge-tts             → Edge 온라인 TTS, 캐시 재생
  Pillow               → 메뉴 이미지 로딩·리사이즈
  google-cloud-dialogflow → 자연어 인텐트 인식

  ※ pyaudio 설치 오류 발생 시:
     sudo apt install -y python3-pyaudio
     (pip 대신 apt 패키지 사용)

     가상환경에서 apt PyAudio를 인식해야 하면 가상환경을 다시 생성:
       rm -rf ~/venv-cafe
       python3 -m venv --system-site-packages ~/venv-cafe
       source ~/venv-cafe/bin/activate
       python -m pip install --upgrade pip setuptools wheel
       pip install -r requirements-rpi.txt

  ※ Pillow 버전 안내:
     apt 기본 Pillow(~8.x, Bullseye)와 pip 최신 Pillow(10.x) 모두 지원됩니다.
     코드가 버전 차이를 자동 감지하여 처리하므로 어느 버전이든 정상 동작합니다.

실행 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  cd cafe_kiosk
  python cafe_kiosk_final.py         ← Windows
  python3 cafe_kiosk_final.py        ← Raspberry Pi / Linux

  ※ Raspberry Pi 듀얼 모니터 구성에서는 xrandr 로 모니터를 자동 감지합니다.
     - 작은 화면(5인치급) → 1번 윈도우: 음성+터치 주문
     - 큰 화면(7인치급)   → 2번 윈도우: 키오스크 주문
     예: 800×480 화면은 1번, 1024×600 화면은 2번으로 자동 배정됩니다.
  ※ Raspberry Pi 단일 소형 화면에서는 탭 모드 + 풀스크린으로 실행됩니다.
  ※ 단일 풀스크린 모드에서는 Escape 키로 풀스크린을 전환할 수 있습니다.
     듀얼 모니터 고정 배치 모드에서는 Escape 키로 프로그램을 종료합니다.

사용 방법

[화면 구성 — 자동 선택]
  화면 크기에 따라 레이아웃이 자동으로 결정됩니다:

  모드 A (Raspberry Pi 듀얼 모니터)
    → xrandr 로 실제 모니터 해상도와 좌표를 읽어 자동 배치
    → 5인치급 작은 화면: 1번 창(음성+터치)
    → 7인치급 큰 화면: 2번 창(키오스크)

  모드 B (일반 듀얼 모니터) → 각 모니터에 창 하나씩 표시
  모드 C (넓은 모니터, ≥1200px) → 좌/우 절반 분할
  모드 D (소형 화면, RPi 7인치 등) → 하나의 창에 탭으로 전환 (기본)
    ├ 일반 소형 : 메뉴판/장바구니/로그 고정 폭 배치
    └ 5인치급 (≤900×520) : 3열 균등 비율 배치 + 설정 패널 기본 숨김
                            헤더 ⚙ 버튼으로 설정 패널 토글
  RPi 단일 화면에서는 자동 풀스크린, Escape 키로 해제


[창 1 — 음성+터치 주문 창]
  - [말하기] 버튼을 눌러 음성으로 주문 (예: "아메리카노 한 잔")
  - 메뉴 버튼을 직접 터치/클릭해서 장바구니에 추가
  - 장바구니의 [+] / [-] 버튼으로 수량 조절
  - 장바구니 메뉴 항목을 누르면 옵션 수정 팝업이 열립니다.
  - [❌ 전체 취소] 버튼으로 장바구니 초기화
  - [직원 호출] 버튼 클릭 시 TTS 안내 + 팝업 표시 (5초 후 자동 닫힘)
  - TTS 볼륨/속도 슬라이더로 음성 안내를 조절합니다.
  - [TTS테스트] 버튼을 누르면 "테스트" 음성이 출력됩니다.
  - 볼륨/속도 설정은 프로그램 종료 후에도 저장되어 다음 실행 시 불러옵니다.
  - 드롭다운으로 마이크 장치 선택 가능

[창 2 — 키오스크 주문 창]
  - 상단 카테고리 탭으로 메뉴 전환
  - 메뉴 카드에 메뉴 이미지가 표시됩니다 (이미지 없는 메뉴는 이모지 대체)
  - 메뉴 카드의 이미지/배경/메뉴명/가격 영역을 눌러 장바구니에 추가
  - 우측 장바구니에서 수량 확인 및 [+] / [-] 조절
  - 장바구니 메뉴 항목을 누르면 옵션 수정 팝업이 열립니다.
  - 우측 상단 ⚙ 설정 버튼에서 TTS 설정, 품절 관리, 관리자 통계를 확인합니다.
  - [주문하기] 버튼으로 이용 방식 → 최종 주문 확인 → 결제수단 선택을 진행합니다.

[두 창 공통]
  - 한 쪽 창에서 메뉴를 추가하면 다른 창 장바구니에도 즉시 반영됩니다.
  - 한 쪽 창을 닫으면 양쪽 모두 종료됩니다.
  - 결제 전 최종 주문 확인 화면에서 주문 메뉴, 옵션, 수량, 합계,
    매장/포장, 결제 예정 금액을 확인하고 [수정하기] 또는 [결제하기]를 선택합니다.
  - 주문 완료 후 주문 번호와 예상 대기시간이 표시됩니다.
    예상 대기시간은 메뉴 1개당 2분으로 계산됩니다.

음성 주문 예시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  주문:
    "아메리카노 한 잔 주세요"
    "카페라떼 아이스 라지 샷추가 두 잔"
    "아아 두 개"            ← 아이스 아메리카노 줄임말
    "아샷추 주세요"         ← 아이스티 샷 추가 줄임말
    "아이스티 샷추가 라지로 주세요"

  대화형 음성 주문:
    메뉴명만 말하거나 옵션이 부족하면 프로그램이 필요한 옵션을 순서대로 질문합니다.

    예시 1)
      사용자: "카페라떼 두 잔"
      프로그램: "카페라떼 핫으로 드릴까요, 아이스로 드릴까요?"
      사용자: "아이스"
      프로그램: "카페라떼 사이즈는 일반으로 할까요, 라지로 할까요?"
      사용자: "라지"
      프로그램: "카페라떼 샷 추가 하시겠어요?"
      사용자: "샷추가"
      → 카페라떼(아이스/라지(L)/샷추가) 2잔 장바구니 추가

    예시 2)
      사용자: "아샷추"
      프로그램: "아이스티 샷 추가 사이즈는 일반으로 할까요, 라지로 할까요?"
      사용자: "일반"
      → 아이스티 샷 추가(아이스/일반) 장바구니 추가

  애매한 키워드:
    "딸기"처럼 여러 메뉴로 해석될 수 있는 단어는 바로 담지 않고
    "딸기에이드 또는 딸기스무디 중 어떤 메뉴인가요?"처럼 다시 질문합니다.

  확인/결제:
    "주문할게요" / "확인" / "결제"

  취소:
    "취소" / "장바구니 비워줘" / "처음부터"

  직원 호출:
    "직원 불러줘" / "직원 호출"

  ※ 음성으로 메뉴가 장바구니에 담기면
     "추가 주문 있으신가요? 더 주문하실 메뉴를 말씀해 주세요.
      없으시면 확인이라고 말씀해 주세요." 라고 안내합니다.

오류 해결 (트러블슈팅)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[문제] "No module named 'tkinter'" 오류
  → (Linux/RPi) sudo apt install python3-tk
  → (Windows) Python 재설치 시 "tcl/tk and IDLE" 옵션 체크 확인

[문제] "No module named '_tkinter'" 오류
  → sudo apt install python3-tk 후 재시도
  → 그래도 안 되면: sudo apt install tk-dev 후 Python 재빌드

[문제] "OSError: PortAudio library not found" 오류
  → sudo apt install portaudio19-dev 후 pip3 install pyaudio 재설치

[문제] pyaudio 설치 실패 (Windows "Microsoft Visual C++" 오류)
  → pip install pipwin
  → pipwin install pyaudio

[문제] pyaudio 설치 실패 (Linux "error: command 'gcc' failed")
  → sudo apt install python3-dev build-essential portaudio19-dev libasound2-dev 후 재시도
  → 또는: sudo apt install python3-pyaudio (apt 버전 사용)

[문제] 한글이 깨지거나 □□□로 표시됨
  → (Linux/RPi) sudo apt install fonts-noto-cjk fonts-noto-color-emoji
  → fc-cache -fv 실행 후 재시작

[문제] 마이크가 인식되지 않음
  → (Linux/RPi) arecord -l 명령으로 마이크 장치 목록 확인
  → USB 마이크 연결 후 재시작
  → 앱 내 드롭다운에서 마이크 장치를 직접 선택 가능
  → 음성 인식 없이 터치/클릭으로만 주문 가능 (기본 기능 정상 동작)

[문제] TTS 음성이 나오지 않음 (Linux/RPi)
  → Edge TTS 사용 시: sudo apt install mpg123 확인
  → 오프라인 폴백 사용 시: sudo apt install espeak-ng espeak-ng-data 확인
  → espeak-ng "테스트" 명령으로 직접 테스트
  → 스피커/헤드폰 연결 및 볼륨 확인: amixer sset Master 80%

[문제] TTS 음성이 나오지 않음 (Windows)
  → Windows 설정 → 시간 및 언어 → 언어 → 한국어 언어팩 설치 확인
  → "Microsoft Heami" 또는 기타 한국어 음성이 설치되어 있어야 합니다.
  → pywin32 미설치 시 PowerShell 폴백 사용: pip install pywin32 으로 속도 개선 가능

[문제] TTS 응답이 느림 (Windows, 말할 때마다 1초 이상 딜레이)
  → pywin32 미설치 상태에서 발생: pip install pywin32
  → 설치 후 재실행하면 SAPI5 COM 직접 호출로 전환되어 딜레이 해소

[문제] Raspberry Pi 듀얼 모니터에서 5인치/7인치 창이 바뀌거나 한쪽으로 몰림
  → xrandr 설치 확인: sudo apt install x11-xserver-utils
  → 현재 모니터 인식 확인: xrandr --query
  → 두 모니터가 connected 상태인지 확인
  → 프로그램은 연결된 모니터 중 면적이 작은 화면을 1번(음성+터치),
     면적이 큰 화면을 2번(키오스크)으로 자동 배치합니다.
  → 두 모니터 해상도가 동일하면 자동으로 구분하기 어려우므로
     5인치/7인치 화면 해상도를 서로 다르게 설정하세요.

[문제] 메뉴 카드에 이미지가 표시되지 않고 이모지만 나옴
  → Pillow 미설치: pip3 install Pillow  또는  sudo apt install python3-pil python3-pil.imagetk
  → cafe_menu_image 폴더 위치 확인: cafe_kiosk/ 폴더 안에 있어야 함 (cafe_kiosk/cafe_menu_image/)
  → 이미지 파일명이 메뉴명과 일치하는지 확인 (예: 아메리카노.png)
  → Pillow 설치 후에도 안 되면: pip3 install --upgrade Pillow

[문제] Dialogflow 연결 오류
  → avis-fcwa-d608a6b1f702.json 파일이 같은 폴더에 있는지 확인
  → 인터넷 연결 확인
  → 파일이 없어도 키워드 매칭으로 정상 동작함
