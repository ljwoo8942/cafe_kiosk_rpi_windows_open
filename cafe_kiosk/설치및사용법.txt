BEAN & BREW Cafe Kiosk 설치 및 사용법
Windows / Raspberry Pi / Linux 지원
문서 갱신 기준: v1.3.2
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 프로그램은 일반 터치 키오스크 사용이 어려운 노약자분들도
음성 안내와 음성 인식으로 주문을 진행할 수 있도록 만든 카페 키오스크입니다.

터치 주문도 지원하지만 핵심 흐름은 다음과 같습니다.

  1. 사용자가 메뉴를 말함
  2. 옵션이 부족하면 프로그램이 다시 질문함
  3. 매장 이용 / 테이크 아웃 선택
  4. 최종 주문 확인
  5. 결제수단 선택 및 결제 방법 음성 안내
  6. 영수증 발행 여부 선택
  7. 주문 번호와 예상 대기시간 표시

1. 권장 환경
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[공통]
  - 인터넷 연결 권장
    음성 인식, Edge TTS, 업데이트 확인, 패키지 설치에 필요할 수 있습니다.
  - 마이크
    USB 마이크를 권장합니다. 마이크가 없어도 터치 주문은 사용 가능합니다.
  - 스피커 또는 모니터 내장 오디오
    TTS 안내 음성을 출력합니다.
  - 터치스크린 또는 마우스

[Windows]
  - Windows 10 / 11
  - Python 3.13.12 기준 개발
  - 설치 스크립트는 Python 3.10 이상 3.14 미만을 사용합니다.
  - Python 3.14와 3.13이 같이 설치된 환경에서는 3.13 계열을 우선 사용하도록 구성되어 있습니다.

[Raspberry Pi / Linux]
  - Raspberry Pi OS Bullseye / Bookworm 또는 일반 Linux
  - Python 3.9 이상
  - 5인치 / 7인치 터치 디스플레이 구성 지원
  - Raspberry Pi에서는 xrandr로 모니터 크기와 위치를 감지합니다.

2. 가장 쉬운 설치 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GitHub Releases에서 최신 설치 파일을 다운로드합니다.

  https://github.com/ljwoo8942/cafe_kiosk_rpi_windows_open/releases

[Windows 일반 사용자]
  1. CafeKiosk-Windows-Setup-1.3.2.exe를 다운로드합니다.
  2. 설치 파일을 실행합니다.
  3. 설치가 끝나면 바탕화면의 BEAN & BREW Cafe Kiosk 바로가기로 실행합니다.

  설치 파일은 다음 작업을 자동으로 처리합니다.
    - 설치 폴더 생성
    - Python 가상환경 생성
    - 필요한 Python 패키지 설치
    - 바탕화면 / 시작 메뉴 바로가기 생성
    - 앱 실행 아이콘 적용

  SmartScreen 경고가 뜰 수 있습니다.
  개인 개발자가 배포한 서명되지 않은 설치 파일에서 발생할 수 있으며,
  실행하려면 추가 정보 → 실행을 선택합니다.

[Windows 무설치 압축본]
  1. CafeKiosk-Windows-Portable-1.3.2.zip을 다운로드합니다.
  2. 원하는 폴더에 압축을 풉니다.
  3. install_windows.ps1을 실행해 필요한 패키지를 설치합니다.
  4. run_windows.cmd로 실행합니다.

  PowerShell 예시:
    powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
    .\run_windows.cmd

[Raspberry Pi 더블클릭 설치]
  1. CafeKiosk-RPi-Installer-1.3.2.zip을 다운로드합니다.
  2. 압축을 풉니다.
  3. 설치하기.desktop 파일을 더블클릭합니다.
  4. 실행 허용 또는 신뢰 확인 창이 뜨면 허용합니다.
  5. 설치 창에서 설치 시작 버튼을 누릅니다.
  6. 권한 확인 창이 뜨면 Raspberry Pi 비밀번호를 입력합니다.
  7. 설치가 끝나면 프로그램 실행 버튼을 누릅니다.

  설치 창이 열리지 않으면 같은 폴더에서 아래 명령을 실행합니다.
    bash install_rpi_gui.sh

[Raspberry Pi / Linux 직접 설치]
  cafe-kiosk-rpi_1.3.2_all.deb 파일을 다운로드한 뒤 아래처럼 설치합니다.

    sudo apt install ./cafe-kiosk-rpi_1.3.2_all.deb
    cafe-kiosk

  deb 설치 파일은 /opt/cafe-kiosk에 프로그램을 설치하고,
  /usr/local/bin/cafe-kiosk 명령과 메뉴 아이콘을 등록합니다.

3. 개발자 / 소스코드 직접 실행
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Windows]
  powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
  .\run_windows.cmd

  수동 실행:
    py -3.13 -m pip install -r requirements-windows.txt
    py -3.13 cafe_kiosk/cafe_kiosk_final.py

[Raspberry Pi / Linux]
  bash install_raspberry_pi.sh
  bash run_raspberry_pi.sh

  부팅 시 자동 실행까지 등록하려면:
    CAFE_KIOSK_AUTOSTART=1 bash install_raspberry_pi.sh

  수동 실행:
    python3 -m venv --system-site-packages ~/venv-cafe
    source ~/venv-cafe/bin/activate
    python -m pip install --upgrade pip setuptools wheel
    pip install -r requirements-rpi.txt
    python cafe_kiosk/cafe_kiosk_final.py

4. 설치되는 주요 구성요소
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[프로그램 파일]
  - cafe_kiosk/cafe_kiosk_final.py
    메인 실행 파일입니다.

  - cafe_kiosk/cafe_menu_image/
    메뉴 카드에 표시되는 이미지 폴더입니다.
    이미지 파일명은 메뉴명과 일치해야 합니다.
    예: 아메리카노.png, 카페라떼.png

  - assets/app_icon.png
  - assets/app_icon.ico
    Windows 바로가기, 설치 파일, 실행 창, Raspberry Pi 메뉴 아이콘에 사용됩니다.

  - VERSION
    설치된 프로그램 버전을 기록합니다.

[사용자별 저장 위치]
  Windows:
    %APPDATA%\BEAN_BREW_Cafe_Kiosk\

  Raspberry Pi / Linux:
    ~/.config/bean_brew_cafe_kiosk/

  이 폴더에는 다음 파일이 저장됩니다.
    - cafe_kiosk.db
      주문 이력, 메뉴 키워드, 음성 인식 실패 로그 등을 저장하는 SQLite DB
    - cafe_kiosk_settings.json
      TTS, 마이크, 관리자 비밀번호, 할인/품절 등 설정
    - tts_cache/
      Edge TTS 반복 문장 캐시
    - logs/
      앱 로그, 오류 로그, 음성 로그, 업데이트 로그
    - Dialogflow 인증 JSON
      설정에서 등록한 경우 저장됩니다.

프로그램 파일과 사용자 데이터가 분리되어 있으므로,
설치 폴더가 /opt/cafe-kiosk처럼 관리자 권한 위치여도 일반 사용자 설정은 정상 저장됩니다.

5. 첫 실행 시 초기 설정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

처음 실행하면 초기 설정 팝업이 표시됩니다.

초기 설정에서 확인할 수 있는 항목:
  - TTS 엔진 자동 선택 상태
  - 마이크 기본 장치 상태
  - Dialogflow 인증 파일 등록 여부
  - 시스템 점검
  - TTS 테스트
  - 주변 소음 보정
  - 설정 창 열기

Dialogflow 인증 파일은 선택 사항입니다.
처음에 등록하지 않아도 프로그램은 키워드 기반 음성 인식으로 정상 동작합니다.
나중에 설정 창의 Dialogflow 등록 버튼으로 언제든 다시 등록할 수 있습니다.

TTS 테스트 버튼은 화면에는 TTS테스트로 표시되고,
실제 음성은 "테스트"라고 출력됩니다.

소음 보정 버튼은 현재 주변 소음을 기준으로 마이크 감도를 다시 맞춥니다.
주변이 너무 시끄럽거나 음성 인식이 잘 안 될 때 사용합니다.

6. 관리자 설정 진입
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

설정 버튼을 누르면 관리자 비밀번호를 입력해야 합니다.

  초기 비밀번호: 1234
  마스터키: root

처음 1234를 입력하면 즉시 새 관리자 비밀번호를 등록해야 합니다.
새 비밀번호는 평문으로 저장하지 않고 PBKDF2-HMAC-SHA256 해시와 salt로 저장됩니다.

비밀번호를 잊었을 때는 비밀번호 입력란에 root를 입력하면
비밀번호가 초기화되고 설정 창에 들어갈 수 있습니다.

주의:
  root 마스터키는 설치 사용자가 복구할 수 있도록 공개된 복구키입니다.
  강한 보안이 필요한 실제 매장 운영 환경에서는 별도 정책을 적용하는 것이 좋습니다.

설정 창 주요 기능:
  - 프로그램 종료
  - TTS 볼륨 조절
  - TTS 속도 조절
  - TTS 높낮이(피치) 조절
  - TTS 엔진 선택
  - TTS 음성 선택
  - 마이크 장치 선택
  - TTS테스트
  - 주변 소음 보정
  - 할인 설정
  - 품절 관리
  - 관리자 통계
  - 오류 로그 확인
  - 진단 저장
  - Dialogflow 등록
  - 업데이트 확인 / 적용

볼륨, 속도, 피치, TTS 엔진, TTS 음성, 마이크 선택은
프로그램을 종료해도 저장되어 다음 실행 시 다시 불러옵니다.

[할인 설정]
  메뉴별로 직접 할인 가격을 입력하거나 할인율(%)을 입력할 수 있습니다.
  할인 해제도 가능합니다.

[품절 관리]
  메뉴를 품절 처리하면 메뉴 카드가 비활성화되고,
  터치/음성 주문 시 품절 안내가 출력됩니다.

[관리자 통계]
  오늘 매출, 인기 메뉴, 음성 인식 실패 로그를 확인할 수 있습니다.
  초기화 버튼을 누르면 통계/로그 내역을 초기화할 수 있습니다.

[오류 로그 / 진단 저장]
  오류 로그 팝업에서 현재 로그를 확인할 수 있습니다.
  진단 저장 버튼을 누르면 저장 위치를 선택해 개발자에게 보낼 수 있는
  텍스트 파일로 저장할 수 있습니다.

8. TTS 엔진과 음성 안내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

설정에서 선택 가능한 TTS 엔진:
  - 자동 선택
  - Edge TTS
  - pyttsx3
  - espeak-ng
  - Windows SAPI5

현재 코드에 Piper TTS 엔진은 포함되어 있지 않습니다.

[자동 선택]
  Edge TTS가 가능하면 우선 사용하고,
  실패하면 플랫폼별 안정적인 TTS로 폴백합니다.

[Edge TTS]
  한국어 음질이 좋고 반복 안내 문장은 캐시됩니다.
  캐시는 프로그램을 종료했다가 다시 실행해도 유지됩니다.
  Windows에서는 내부 오디오 재생 방식을 사용하고,
  Raspberry Pi / Linux에서는 mpg123 같은 mp3 재생기를 사용합니다.

[Windows SAPI5]
  Windows 한국어 음성팩을 사용합니다.
  한국어 음성이 없다면 Windows 설정 → 시간 및 언어 → 언어에서
  한국어 음성팩을 설치하세요.

[espeak-ng]
  Raspberry Pi / Linux에서 오프라인 폴백 TTS로 사용합니다.
  높낮이(피치)와 속도 조절을 지원합니다.

필요 패키지:
  Windows:
    pip install pyttsx3 edge-tts pywin32

  Raspberry Pi / Linux:
    sudo apt install mpg123 espeak-ng espeak-ng-data
    pip install edge-tts pyttsx3

9. 화면 배치
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Raspberry Pi 듀얼 모니터]
  xrandr로 실제 모니터 해상도와 위치를 읽어 자동 배치합니다.
  면적이 작은 화면은 1번 창(음성+터치 주문),
  면적이 큰 화면은 2번 창(키오스크 주문)으로 배치됩니다.

  일반적인 구성:
    - 5인치 800x480 화면 → 음성+터치 주문 창
    - 7인치 1024x600 화면 → 키오스크 주문 창

  듀얼 모니터 고정 배치에서는 Escape 키를 누르면 프로그램이 종료됩니다.

[단일 소형 화면]
  하나의 창 상단에 음성+터치 주문 / 메뉴 키오스크 전환 버튼이 표시됩니다.
  Raspberry Pi 단일 화면에서는 자동 풀스크린으로 실행됩니다.
  Escape 키로 풀스크린을 전환할 수 있습니다.

[일반 Windows / 넓은 모니터]
  화면이 넓으면 음성+터치 창과 키오스크 창을 좌우로 나누어 표시합니다.

10. 주문 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[터치 주문]
  1. 메뉴 카드 또는 메뉴 버튼을 누릅니다.
  2. 음료는 온도, 사이즈, 샷 추가 옵션을 선택합니다.
  3. 장바구니에 담깁니다.
  4. 장바구니의 + / - 버튼으로 수량을 조절합니다.
  5. 장바구니 항목을 누르면 옵션 수정 팝업이 열립니다.

[음성 주문]
  말하기 버튼을 누르고 메뉴를 말합니다.

  예시:
    아메리카노 한 잔 주세요
    카페라떼 아이스 라지 샷추가 두 잔
    아아 두 잔
    아샷추 주세요
    아이스티 샷추가 라지로 주세요

  옵션이 부족하면 프로그램이 이어서 질문합니다.

  예시:
    사용자: 카페라떼 두 잔
    프로그램: 카페라떼 핫으로 드릴까요, 아이스로 드릴까요?
    사용자: 아이스
    프로그램: 카페라떼 사이즈는 일반으로 할까요, 라지로 할까요?
    사용자: 라지
    프로그램: 카페라떼 샷 추가 하시겠어요?
    사용자: 샷추가
    결과: 카페라떼(아이스/라지(L)/샷추가) 2잔 추가

[애매한 메뉴명]
  딸기처럼 여러 메뉴로 해석될 수 있는 단어는 바로 담지 않습니다.
  딸기에이드 또는 딸기스무디 중 어떤 메뉴인지 다시 질문합니다.

[이용 방식 음성 처리]
  매장 이용 또는 테이크 아웃도 음성으로 선택할 수 있습니다.

  예시:
    매장에서 먹고가요
    포장해서 가져갈게요
    매장
    포장

[최종 주문 확인 음성 처리]
  최종 주문 확인 화면에서 수정하기 또는 결제하기를 음성으로 말할 수 있습니다.

  예시:
    수정하기
    결제하기

11. 메뉴 옵션
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[기본 음료]
  1. 온도 선택: 아이스 / 핫
  2. 사이즈 선택: 일반 / 라지(L)

가격:
  - 핫 선택 시 500원 할인
  - 라지(L) 선택 시 500원 추가

[커피 메뉴]
  온도와 사이즈 선택 후 샷 추가 여부를 선택합니다.
  샷 추가 금액은 500원입니다.

[아이스티 샷 추가]
  - 커피 카테고리에 표시됩니다.
  - 가격은 4,500원입니다.
  - 아이스 전용 메뉴입니다.
  - 옵션 선택에서는 사이즈만 선택합니다.
  - 음성으로 아샷추라고 말해도 인식합니다.

[핫 전용 메뉴]
  쌍화차, 루이보스티, 캐모마일, 유자티, 핫초코, 에스프레소는 핫 전용입니다.

[디저트]
  온도, 사이즈, 샷 옵션 없이 바로 장바구니에 담깁니다.

12. 결제와 주문 완료
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

주문하기를 누르면 다음 순서로 진행됩니다.

  1. 매장 이용 / 테이크 아웃 선택
  2. 최종 주문 확인
  3. 결제수단 선택
  4. 결제수단별 안내 음성 출력 후 약 10초 대기
  5. 영수증 발행 여부 선택
  6. 주문 완료

결제수단 안내 음성:
  - 신용/체크카드: 카드를 대거나 끝까지 넣어주세요.
  - 바코드: 바코드를 스캔해 주세요.
  - 계좌이체: 보내실 계좌는 1111-2222-333-4444.

영수증 발행 팝업이 뜨면 TTS로
"영수증 필요하신가요?"라고 안내합니다.

주문 완료 화면에는 다음 정보가 표시됩니다.
  - 주문 번호
  - 주문 내역
  - 결제수단
  - 영수증 발행 여부
  - 예상 대기시간

예상 대기시간은 메뉴 수량 1개당 2분으로 계산됩니다.
예: 메뉴 3개 주문 → 예상 대기시간 6분

13. 세션 자동 초기화
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

주문 중 90초 동안 입력이 없으면 장바구니와 진행 중인 주문 팝업을 자동 초기화합니다.

사용자 터치나 음성이 감지되면 안내 문구는 초기 상태로 돌아갑니다.
주문 완료 후에는 TTS 출력이 끝난 뒤 10초 정도 기다렸다가 안내 문구를 초기 상태로 되돌립니다.

반복 터치로 인한 멈춤을 줄이기 위해 주문하기 버튼과 팝업 흐름에는
중복 실행 방지 처리가 들어 있습니다.

14. Dialogflow 사용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dialogflow는 선택 기능입니다.
인증 파일이 없어도 키워드 기반 음성 인식으로 주문할 수 있습니다.

사용하려면 Google Cloud 서비스 계정 JSON 파일이 필요합니다.

등록 방법:
  1. 설정 창을 엽니다.
  2. Dialogflow 등록 버튼을 누릅니다.
  3. 전달받은 JSON 파일을 선택합니다.
  4. 프로그램이 안전한 설정 폴더로 복사하고 다음 실행부터 우선 사용합니다.

이미 프로그램 폴더 또는 사용자 설정 폴더에 인증 파일이 있으면
프로그램 시작 시 자동으로 먼저 불러옵니다.

현재 코드의 기본 인증 파일명:
  avis-fcwa-d608a6b1f702.json

15. 업데이트 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로그램 시작 시 GitHub Releases의 최신 버전을 확인합니다.
새 버전이 있으면 설정 버튼 테두리가 강조됩니다.

설정 창의 업데이트 버튼에서 최신 설치 파일을 받을 수 있습니다.

업데이트 안전장치:
  - GitHub Release 자산 다운로드
  - SHA256 검증
  - 적용 전 기존 파일 백업
  - 실패 시 복구 스크립트 또는 복구 경로 안내
  - 사용자 설정, 주문 DB, TTS 캐시는 덮어쓰지 않음

주의:
  직접 소스 폴더에서 실행하는 개발자 환경에서는
  Git이 설치되어 있고 해당 폴더가 Git 저장소일 때 업데이트 기능이 더 원활합니다.

16. 삭제 방법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Windows 설치형]
  Windows 설정 → 앱 → BEAN & BREW Cafe Kiosk 제거

  제거 시 다음 항목까지 정리됩니다.
    - 설치 폴더
    - .venv-windows
    - TTS 캐시
    - Dialogflow 인증 파일
    - 사용자 설정
    - 주문 이력 DB
    - 로그
    - 업데이트 임시 파일

[Windows 무설치 압축본]
  압축을 푼 폴더에서 실행:
    powershell -ExecutionPolicy Bypass -File .\uninstall_windows.ps1 -RemoveAppRoot

[Raspberry Pi / Linux deb 설치]
  sudo apt remove cafe-kiosk-rpi

  /opt/cafe-kiosk 프로그램 파일, 가상환경, 런처, 메뉴 아이콘,
  사용자 설정, 주문 DB, 로그, 캐시, 업데이트 임시 파일까지 정리됩니다.

[Raspberry Pi / Linux 직접 설치]
  bash uninstall_raspberry_pi.sh

  사용자 설정과 주문 DB를 보존하려면:
    bash uninstall_raspberry_pi.sh --keep-user-data

17. 오류 로그와 진단 파일
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로그램 로그 위치:

  Windows:
    %APPDATA%\BEAN_BREW_Cafe_Kiosk\logs\

  Raspberry Pi / Linux:
    ~/.config/bean_brew_cafe_kiosk/logs/

저장되는 로그:
  - app.log
  - error.log
  - speech.log
  - update.log

설정 창에서 오류 로그 버튼을 누르면 현재 로그를 볼 수 있습니다.
진단 저장 버튼 또는 오류 로그 팝업의 텍스트 저장 버튼을 누르면
사용자가 원하는 위치에 개발자 전달용 .txt 파일을 저장할 수 있습니다.

Dialogflow 인증키나 개인 토큰 같은 민감한 값은 진단 파일에 직접 기록하지 않습니다.

설치 로그:
  Windows:
    설치 폴더\install_logs\

  Raspberry Pi / Linux 직접 설치:
    실행 폴더/install_logs/

  deb 설치:
    /var/log/bean-brew-cafe-kiosk-install.log

18. 자주 발생하는 문제
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[Windows에서 설치 후 바로 실행되지 않는 것처럼 보임]
  시작 안내창이 먼저 표시됩니다.
  프로그램이 이미 실행 중이면 다시 누르지 않아도 된다는 안내가 뜹니다.
  잠시 기다리면 메인 프로그램이 표시됩니다.

[Windows에서 pyaudio 설치 실패]
  pip install pipwin
  pipwin install pyaudio

  또는 설치 파일을 다시 실행해 복구 설치를 시도합니다.

[Windows에서 TTS가 느림]
  pywin32 설치 여부를 확인합니다.
  pip install pywin32

[Windows에서 한국어 TTS가 영어처럼 나옴]
  Windows 설정 → 시간 및 언어 → 언어 및 지역에서 한국어 음성팩을 설치합니다.

[Raspberry Pi에서 ALSA/JACK 경고가 많이 출력됨]
  사용하지 않는 오디오 장치 탐색 중 출력되는 경고일 수 있습니다.
  프로그램이 정상 실행되고 마이크/스피커가 동작하면 치명적인 오류는 아닙니다.
  실제 녹음/재생이 안 되면 arecord -l, aplay -l로 장치를 확인하세요.

[Raspberry Pi에서 TTS 피치가 조절되지 않음]
  espeak-ng와 espeak-ng-data가 설치되어 있는지 확인합니다.
    sudo apt install espeak-ng espeak-ng-data

[마이크가 인식되지 않음]
  - USB 마이크 연결 확인
  - 프로그램 설정에서 마이크 장치 선택
  - 소음 보정 실행
  - Raspberry Pi에서는 arecord -l 확인

[메뉴 이미지가 표시되지 않음]
  - cafe_kiosk/cafe_menu_image 폴더 위치 확인
  - 이미지 파일명이 메뉴명과 같은지 확인
  - Pillow 설치 확인
    Windows: pip install Pillow
    Raspberry Pi: sudo apt install python3-pil python3-pil.imagetk

[한글 또는 이모지가 깨짐]
  Raspberry Pi / Linux:
    sudo apt install fonts-noto-cjk fonts-noto-color-emoji
    fc-cache -fv

[Dialogflow 연결 오류]
  - 인증 JSON 파일 등록 여부 확인
  - 인터넷 연결 확인
  - 인증 파일이 없어도 기본 키워드 인식으로 동작 가능

[최종 주문 확인 팝업이나 주문 완료 팝업이 하얗게 보임]
  최신 릴리즈를 사용하세요.
  작은 화면 대응과 팝업 스크롤/크기 보정이 들어가 있습니다.
